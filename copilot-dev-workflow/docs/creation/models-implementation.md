# モデル割当の実装

各21担当のネイティブagentsファイルにmodel欄を追加。要件・設計・独立レビュー・動作確認・check・impact・mutateの9担当は高性能、残る12担当は軽量。SKILL.md/操作入口はmodel-policy.mdを読み、対応担当へ実行を渡す。初期設定の最終確認と本番前後の確認も高性能へ戻す。

インストーラーがagentsを配置。利用者の設定は上書きしない。モデル不可・上書き・実モデル不明時は停止する運用契約を明記。これはホストを強制監視するPython機能ではなく、実行担当の確認手順である。

各model欄を更新して保守し、定義の再読込と実ホストの選択確認を行う。Auto/inheritや暗黙の軽量降格で代用しない。
