# Gemini版との一致

正本：Gemini版v0.6.0、Gitコミット1f8229a。工程・ルール・必要成果物・品質基準は同じです。モデルの回答や生成コードまで一致する保証はありません。

| 区分 | 確認方法 |
|---|---|
| Pythonランタイム | gdw→cdwの識別子置換後に全文一致 |
| 14工程のスキル、共通規約、テンプレート、可変領域 | 製品名・配置パス・gdw→cdw識別子の明示置換後に全文一致 |
| 7操作入口 | Gemini TOMLの本文を保持し、Copilotスキルへ変換。引数の表現だけ変更 |
| 実行環境固有部分 | 互換性・公式出典・Notion接続・レビュー起動・モデル定義を個別レビュー |
| 21担当のエージェント | 本文は製品パス置換後に一致。modelとツール欄は各製品のネイティブ仕様を使用 |
| モデル実行規約 | 共通契約は一致。ホスト固有の起動方法とモデルIDは個別に定義 |
| インストーラー | Copilot配置へ変更。既存指示保持・競合停止・再導入を同じテストで確認 |

全対象の元パス・移植先・ハッシュ・置換一覧は[一致検査記録](creation/evidence/parity.json)に記載しています。テストは以下で実行できます。

```sh
python -m unittest discover -s tests -p test_parity.py -v
```

更新時はGeminiの共通仕様を正本として両版へ反映し、元ファイルから置換後の全文一致を再確認してmanifestを更新します。Copilot版だけで共通仕様を変更したままハッシュを追認しません。実行環境固有の変更は別途レビューします。CIは配布版が確認済みmanifestから変わっていないかを検出します。manifest自体の変更もレビュー対象です。

過去のGemini作成記録をCopilotの実行証拠として転用せず、この版の検証記録をdocs/creation/へ保存します。歴史は元Gitコミットで追跡できます。
