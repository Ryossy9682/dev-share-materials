Cloud Run FunctionsのPDF、各技術の設定・実装サンプル、README、検証記録を同梱しています。
Terraformはminimal/detailedの2種類、GitHub ActionsはMIN/MAXの2種類を収録しています。
GitHub Actionsはvariantsから一方だけをコピーします。利用先の環境変数・IAM・保護ルールの設定が必要です。
自動生成の実行結果、依存バイナリ、ローカル環境、認証ファイルは含めません。
