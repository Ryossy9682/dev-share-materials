# Google Cloud Run functions 開発マニュアル・サンプル

1. `01-cloud-run-functions-developer-guide.html`をブラウザーで開きます。
2. `samples/hello-function/README.md`に沿ってサンプルを動かします。

HTMLは外部スクリプトや画像を使わず、オフラインで閲覧できます。図解、章別目次、コードのコピー、印刷・PDF保存に対応しています。サンプルにはPython関数、PowerShellスクリプト、テスト、配置設定例、計測・コスト比較のひな形を含みます。

本書の設定例は学習・比較用です。クラウドへ自動で配置されることはありません。

公式情報： https://docs.cloud.google.com/run/docs/deploy-functions
