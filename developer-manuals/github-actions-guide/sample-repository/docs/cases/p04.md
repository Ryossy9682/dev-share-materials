# P04 不変イベントの追記型Incremental

場面：event_idが一意で、既存イベントの更新・削除がないログ。

サンプル：`projects/patterns/models/patterns/p04_events_incremental.sql`

| 比較 | 内容 |
|---|---|
| メリット | 新しいIDだけを追加する。再実行の重複を避けやすい。 |
| デメリット | 本例のNOT EXISTSは既存対象の読取が増える。既存イベント修正は拾わない。 |

確認例：phase1の3イベント→phase2の4イベント。同じ入力を再実行すると新規対象SELECTは0件です。

判断上の注意：BigQuery用サンプルはmerge戦略です。他アダプターのappend設定をそのまま持ち込まないでください。入力のuniqueテストも必要です。

事例は架空データに基づく教材です。実行手順は`docs/01-quickstart.md`、変更シナリオは`docs/02-change-scenarios.md`を参照してください。
