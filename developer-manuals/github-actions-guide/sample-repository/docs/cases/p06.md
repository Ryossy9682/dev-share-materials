# P06 日付単位のinsert_overwrite

場面：直近数日の注文・集計が修正され、対象日を全件再構成できる。

サンプル：`projects/patterns/models/patterns/p06_orders_insert_overwrite.sql`

| 比較 | 内容 |
|---|---|
| メリット | 対象日に含まれる削除も反映できる。処理範囲を日付で管理しやすい。 |
| デメリット | 対象日ごとに全行が必要。選び忘れた過去日は更新されない。 |

確認例：rebuild_datesの3日を再構成し、phase2のpaid合計は349になります。空のパーティションを消すには置換対象日を明示します。

判断上の注意：変更行だけをSELECTしてpartitionを置き換えると、変更のない正しい行が消えます。

事例は架空データに基づく教材です。実行手順は`docs/01-quickstart.md`、変更シナリオは`docs/02-change-scenarios.md`を参照してください。
