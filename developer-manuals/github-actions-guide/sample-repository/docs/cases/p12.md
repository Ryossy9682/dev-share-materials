# P12 BigQueryネイティブMaterialized View

場面：単純な集計を高頻度に読み、DWHが維持する結果を使いたい。

サンプル：`reference-only/native-materialized-view.sql.example`

| 比較 | 内容 |
|---|---|
| メリット | 対応する集計では参照計算を減らせる候補。BigQuery側の自動更新を使える。 |
| デメリット | SQL・更新・ソースの制約、保存・更新費用がある。全クエリの高速化を保証しない。 |

確認例：ネイティブDDLの参考例です。dbtのmaterialized_view対応はエンジン・アダプター・版で確認します。この教材のdbt buildでは作成しません。

判断上の注意：dbtのTable/Incremental、通常View、DWHのMaterialized Viewを同じ仕組みとして扱わないでください。

事例は架空データに基づく教材です。実行手順は`docs/01-quickstart.md`、変更シナリオは`docs/02-change-scenarios.md`を参照してください。

出典： https://docs.cloud.google.com/bigquery/docs/materialized-views-intro
