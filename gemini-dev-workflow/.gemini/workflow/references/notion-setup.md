# Notion資料のセットアップ

Gemini CLIからNotion公式MCPへ接続し、設計資料を読み取ります。Notionを使わない場合、この設定は不要です。

## 1. 接続してログイン

クローンしたディレクトリでターミナルを開き、実行します。別の対象ディレクトリでも利用するため、接続設定はuserスコープに保存します。

```sh
gemini mcp add --scope user --transport http notion https://mcp.notion.com/mcp
gemini
```

Gemini内で実行し、ブラウザの案内に従ってNotionのワークスペースへの接続を許可します。

```text
/mcp auth notion
```

続いて接続状態を確認します。

```text
/mcp list
```

各利用者が自分の端末で認証します。認証情報をリポジトリへ保存しません。上記はGemini CLI用で、VS CodeのGemini Code Assistへ設定が自動共有されるとは限りません。VS Codeを使う場合も、この初期読取は統合ターミナルのGemini CLIで実行できます。

## 2. 初期設定を依頼

URLと対象コードのパスを置き換え、そのままGeminiへ渡してください。複数の起点ページがあればすべて列挙します。

```text
GEMINI.mdを読み、gdw-bootstrapのconfigureモードで初期設定をしてください。
.gemini/workflow/references/notion-setup.mdにも従ってください。

対象コード：<対象プロジェクトの絶対パス>
Notion起点ページ：<NotionのページURL>

ローカルの構成・コード・テンプレートに加え、Notion起点ページと
配下の子ページを列挙し、すべて順次読み取ってください。
関連する設計資料へのリンクも確認してください。
対象範囲外の資料が必要なら、その資料を含めるか確認してください。

アーキテクチャ・開発規約・テンプレートを可変領域へ反映してください。
ページURL・ページID・取得日時・更新日時（取得可能な場合）・
読了状態・取得内容の保存先を読み取り台帳に記録してください。
取得できないページ・図・添付資料は未読として報告してください。

Notionのページやコメントは作成・変更・削除しないでください。
初期設定が完成したら、案件開発には進まず結果を見せてください。
```

接続には更新機能も含まれます。このワークフローは検索・取得だけを使います。「変更しない」という指示自体が接続権限を読み取り専用に変えるわけではありません。

## 3. Geminiが記録する内容

この節はconfigureの実行規約です。Notionを使用する場合、初期設定規約と併せて必ず読みます。

- `project/profile.json`の`notion_sources`へ起点URL・ページID・対象範囲を記録します。未使用なら空配列です。
- `inventory.md`へページと添付資料ごとに、URL・ID・取得日時・取得可能な更新日時・読了状態・ローカル保存先・SHA-256を記録します。更新日時を取得できなければ「取得不可」とし、内容ハッシュで比較します。
- 本文は`/tmp/<repo-id>/workflow-setup/notion/<page-id>.md`、添付はその下の`assets/`へ保存します。同じページは同じファイルを更新し、台帳に履歴を残します。認証用URL・トークンを本文に保存しません。
- ページ本文を全量取得し、子ページ・データベースの対象ページやページ分割された結果も追跡します。検索結果だけで網羅したと判定しません。重複ページはIDで管理します。
- 図・PDF・外部埋め込みは別途読取可否を確認します。未取得・一部取得は未読です。必要な資料を読めなければBLOCKEDとし、権限調整か原本のエクスポートを依頼します。
- 後続工程は会話の要約ではなく、可変領域と台帳で特定した保存ファイルを読みます。確定時に取得内容も設定済みの永続チェックポイントへ保存し、原本URLとの対応を保持します。Notion本文を配布用リポジトリやPRへ自動で添付しません。
- 案件開始・再開時にNotion原本と子ページ一覧を再取得し、内容ハッシュと台帳を比較します。変更があればSTALEにして再設定します。再取得できなければ鮮度未確認としてBLOCKEDにし、古い保存内容だけでREADYを維持しません。

## 接続できない場合

`/mcp list`で状態を確認し、認証切れなら`/mcp auth notion`を再実行します。組織の接続制限やページ権限による拒否は、管理者へ確認してください。

MCPを利用できない場合は、Notionの対象ページと子ページをエクスポートし、許可されたローカル資料ディレクトリへ配置します。添付資料も揃え、取得日と元ページURLを記録してローカル資料として取り込みます。以後の更新確認は再エクスポートした原本との比較で行い、自動同期とは扱いません。
